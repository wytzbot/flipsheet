# FlipSheet — Marketplace Listing

## Short description
Clean spreadsheet data, find duplicate rows and automate recurring Google Sheets maintenance.

## Full description
FlipSheet helps people keep working spreadsheets clean without repeating the same manual cleanup every day.

Select a range in Google Sheets and analyze it for duplicate rows, whitespace problems and malformed email-like values. Clean text safely while preserving formula cells. Then schedule recurring maintenance for the selected sheet and range.

### Free
- Analyze selected ranges
- Clean text safely
- Find duplicate rows
- Validate email-like values
- Standardize text
- Up to 500 rows per operation
- 2 daily automations

### Pro
- Larger ranges
- More recurring automations
- Advanced recurring maintenance workflows
- Priority support
- Monthly and yearly recurring billing

### Privacy
Core spreadsheet transformations execute through Google Apps Script against the user's active spreadsheet. FlipSheet does not need to copy spreadsheet cell contents into its database for the core cleanup workflow.
